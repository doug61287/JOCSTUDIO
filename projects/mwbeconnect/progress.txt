## Codebase Patterns - MWBEFinder

### Project Structure
- `/search/` - Next.js search interface (React + Supabase)
- `/landing/` - Marketing landing page
- `prd.json` - Product requirements document
- `ralph.sh` - Autonomous iteration script

### Technology Stack
- Frontend: React + Next.js + Tailwind CSS
- Database: Supabase (PostgreSQL)
- Deployment: Vercel
- API: Supabase JavaScript client

### Database Patterns
- Table: `businesses` with 1.7M+ records
- Full-text search enabled on `business_name`, `services_description`
- Indexes on `address_city`, `address_state`, `certification_type`
- Row Level Security (RLS) enabled - public read access

### Frontend Patterns
- Use functional components with hooks
- Mobile-first responsive design
- Loading states with skeleton screens
- Error boundaries for graceful failures

### Search Implementation
- Supabase `.or()` for text search across multiple fields
- `.range()` for pagination (20 results per page)
- URL query params for filter persistence
- Debounced search input (300ms)

### Styling Conventions
- Primary color: #10b981 (green)
- Dark background: #0f172a (slate-900)
- Use Tailwind utility classes
- Mobile breakpoint: 768px

### Critical Learnings
- NEVER expose Supabase service_role key in frontend
- Use `.select('*', { count: 'exact' })` for pagination counts
- Handle rate limits - Supabase has 60 req/min on free tier
- Mobile touch targets minimum 44px
- Use history.pushState for URL updates without page reload
- Debounce autocomplete queries to reduce API calls
- Escape key should close modals and dropdowns
- Use aria attributes for accessibility

### Learnings for Future Iterations
- **URL State Management**: Use history.pushState() instead of replaceState() for proper back/forward navigation
- **Autocomplete UX**: Highlight current selection, support keyboard nav, show location context
- **Modal Accessibility**: Use role="dialog", aria-modal, trap focus, escape to close
- **Loading States**: Skeleton screens > spinners for content placeholders
- **Error Recovery**: Always provide retry action, show specific error messages
- **Mobile First**: Start with mobile styles, add desktop enhancements at breakpoints
- **Touch Targets**: iOS/Android require 44px minimum for reliable tap detection
- **Supabase Queries**: Use single query with .or() rather than multiple queries for efficiency
