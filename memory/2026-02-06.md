## Smart Thermostat Project
- Doug has boiler with only R and W wires (no C wire)
- Looking to solve upstairs/downstairs temperature imbalance
- House has drafty downstairs where current thermostat is located
- Bedroom upstairs gets too warm as a result

### Solution Selected
- **Ecobee SmartThermostat** with SmartSensor for upstairs
- **Honeywell THP9045A2098 C-Wire Adapter** (mounts at boiler)
- Adapter uses existing 2-wire cable to send power to thermostat
- Remote sensor will allow "Follow Me" mode for balanced heating
