## Training Data Collection (ML Foundation)

**Log every selection for machine learning:**

### Data Captured:
- Path taken (Wall → New Partition → Drywall)
- Keywords from description
- Final item code selected
- Time to complete (ms)
- User ID
- Project context

### API Endpoints:
```
POST /training/selections     → Log a selection
GET  /training/stats          → Aggregate stats
GET  /training/path/:path     → Items selected via path

```

### Schema (Prisma):

## Architecture Decisions Made

| Decision | Choice | Reason |
|----------|--------|--------|
| Railway for Backend | Yes | Easy Node.js, free tier |
| tsx over tsc | Yes | TS errors exist but tsx runs fine for beta |
| DATABASE_URL | Pooler | Use aws-1 pooler connection |
| CORS | CORS_ORIGIN=* | credentials:true incompatible with multiple origins |
| API calls | Direct | Frontend calls Railway URL directly |
| Catalogue | In-memory | 65k items load in 111ms |
| Translation | Smart | Synonyms + division hints > simple keywords |
| Selection | Chat-based | Guided tree > endless scrolling |
| ML Training | Log all | Every selection trains future recommendations |
