### Quantity Tier Multipliers - SHIPPED (commit 393e70d)
**Big feature**: Shows volume discount savings in real-time

**Implementation:**
- Parsed 7,940 quantity tier multipliers from H+H CTC PDFs
- Created `tier-map.json` (3.6MB) with AddDeductTier data
- `calculateAdjustedPrice()` applies tier adjustments based on quantity
- UI shows "Multiplier: [tier label]" with cyan styling
- Displays price adjustment per unit AND total savings amount
- TrendingDown icon indicates savings

**Example Flow:**
- User traces 47 sprinkler heads @ $126.72 each
- System detects Qty 26-50 tier → -$3.38/unit
- Shows: "Multiplier: Qty 26-50 • Save $158.86"

**Why This Matters:**
- Estimators leave money on table by not applying volume tiers
- H+H contract has built-in discounts most people don't use
- JOCHero makes this automatic and visible
