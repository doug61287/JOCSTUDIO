## Sub-agent Spawning Fixed ✅

After yesterday's failed attempt, finally got the config right:

**Wrong approach (yesterday):**
```json
"agents.defaults.subagents.allowedAgents": ["*"]  // wrong field, wrong location
```

**Correct approach (today):**
```json
"agents.list[0].subagents.allowAgents": ["*"]  // per-agent level, no "ed"
```

Key learnings:
- `allowAgents` not `allowedAgents` (no "ed")
- Goes at per-agent level (`agents.list[].subagents`), not defaults
- Defaults only take: `maxConcurrent`, `archiveAfterMinutes`, `model`, `thinking`

Verified working: `allowAny: true` in agents_list response.
