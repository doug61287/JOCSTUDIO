# 2026-02-15 — Project Brain / Estimator Copilot Evolution

## Major Strategic Shift: Copilot Over Automation

Big positioning decision today: **Estimator augmentation, not replacement**.

### Why This Matters
- Estimators are the **buyers** of construction software
- "AI that replaces estimators" = threatening, hard sell
- "AI copilot that makes estimators faster" = welcomed, easy sell
- Same underlying tech, completely different GTM

### Product Name Candidates
Still workshopping: BidBrain, SpecScout, ProjectPilot, EstiMate

## Estimator Pain Points Mapped

Key problems Project Brain can solve:
1. **Spec Q&A** - "What's the paint finish for corridor walls?" (currently: Ctrl+F through 500 pages)
2. **Liquidated Damages** - Quick answers on LD amounts/conditions
3. **Addenda Change Tracking** - What changed between Addendum 1 and 2?
4. **Warranty Requirements** - "What's the warranty period for HVAC?"
5. **Cross-Document References** - "Section 09 91 13 says see Division 1" → find it instantly

## 3-Week MVP Plan

**Week 1**: PDF upload, chunking, vector indexing, basic Q&A
**Week 2**: Construction-specific features (spec parsing, cross-referencing)
**Week 3**: JOCHero integration
