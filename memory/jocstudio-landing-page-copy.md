Every JOC estimator knows this pain:

**📋 You finish your takeoff.** Quantities look good. Measurements are solid.

## Design System Notes

### Colors
- **Trust Blue Primary:** #1E3A5F
- **Trust Blue Secondary:** #2D5A87
- **Accent (CTA):** #FF6B35 (warm orange for contrast)
- **Success:** #28A745
- **Background Light:** #F8FAFC

### Typography
- **Headlines:** Bold, modern sans-serif (e.g., Inter, Söhne)
- **Body:** Clean, readable (16px base)
- **Emphasis:** Semi-bold for feature names

### Spacing
- Generous whitespace between sections

- Clean, modern UI screenshots
- Minimal illustrations (not cartoonish)
- Real contractor photography where possible (diverse, professional)
