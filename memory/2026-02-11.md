### Completed Features
- MVP Takeoff Tool with PDF viewer, measurements, JOC catalogue, CSV export
- 65,331 NYC H+H CTC 2024 items parsed into `product/data/nyc-hh-ctc-2024.json`
- Translation Machine v2 with synonyms, quantity extraction, division hints, smart scoring
- Guided Estimation Assistant using official TOC hierarchy (25 divisions, 151 sections, 462 subsections)
- Bluebeam-style bottom toolbar (pan/select/text tools, zoom, page nav, scale)
- Pan tool with cursor change, Ctrl+Wheel zoom, Shift+Wheel horizontal pan
- Resizable thumbnails, fixed white screen at high zoom (MAX_RENDER_SCALE=1.0)

### Key Technical Decisions
- **MAX_RENDER_SCALE = 1.0**: Large drawings can exceed canvas limits; CSS handles all zoom
- **Shallow Selectors**: Components only subscribe to needed store fields (prevents re-render loops)
- **TOC Hierarchy Lookup**: 4-digit codes check SECTIONS first, then SUBSECTIONS
- **Native Wheel Listener**: passive:false required to block browser Ctrl+Wheel zoom
- **PDF.js**: Version 4.10.38 pinned, worker from unpkg CDN
